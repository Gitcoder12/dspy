# Portfolio Notes — DSPy Fork

## In plain language

DSPy is a framework for building language-model programs from modules and metrics, then improving them systematically instead of relying only on hand-written prompts.

## Technical context

This repository is a fork of the upstream Stanford NLP DSPy project. The upstream project owns the core code, documentation and release direction. Portfolio contributions must be clearly distinguished from upstream authorship, preserve the original licence and follow upstream contribution/release conventions.

## What this repository is

- Fork: [stanfordnlp/dspy](https://github.com/stanfordnlp/dspy)
- This is not original authorship of DSPy.
- Upstream source, licence, documentation, maintainers and release history remain authoritative.
- This folder records local learning goals, portfolio experiments and contribution notes only.
