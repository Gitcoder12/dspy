# Agent and Skills Notes — DSPy Fork

## Attribution rule

This is upstream code from stanfordnlp/dspy. Do not remove licence notices, rewrite the upstream README as if this were original code or claim upstream implementation as portfolio authorship.

## Bounded agent workflow

- Read upstream AGENTS.md/CONTRIBUTING.md if present and follow their precedence.
- Inspect issue/PR history before editing.
- Prefer local examples and benchmark notebooks in a separate directory.
- For upstream fixes, make a small patch with tests and submit it upstream when appropriate.
- Report exact tests, versions, datasets, metrics and failures.
- Do not merge, release or publish autonomously.

## Skill areas

- DSPy module and signature design.
- Metric design and optimizer evaluation.
- Reproducible dataset and prompt/program benchmarks.
- API compatibility and Python package testing.
- Attribution, licence and upstream contribution hygiene.
